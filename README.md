# Fut-Ultimate

Simulador y gestor de fútbol con interfaz original, adaptable a móviles y escritorio.

## Funciones iniciales
- Panel principal y estadísticas.
- Creación y administración de clubes.
- Registro de jugadores con posición, dorsal y media editable al crearlos.
- Clasificación automática.
- Simulación básica de jornadas según la media de las plantillas.
- Guardado local en el navegador.
- PWA instalable y caché básica para uso sin conexión.

## Publicación
Activa GitHub Pages desde **Settings → Pages → Deploy from a branch → main / root**.

> Esta es la primera base funcional. Los datos se guardan en el dispositivo/navegador donde se usan; todavía no existe sincronización entre usuarios o dispositivos.
